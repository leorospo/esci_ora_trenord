# Esci ora

App iOS personale che mostra sulla schermata di blocco (Live Activity) i prossimi treni utili del tragitto casa-lavoro e quanto tempo resta prima di dover uscire di casa.

Documentazione del progetto in [`docs/`](docs/).

## Dati
- Orari programmati: GTFS Trenord, open data di Regione Lombardia, licenza CC-BY 4.0.
- Ritardi in tempo reale: letti direttamente dall'app, per uso personale. Non vengono salvati né ripubblicati in questo repository o altrove.
